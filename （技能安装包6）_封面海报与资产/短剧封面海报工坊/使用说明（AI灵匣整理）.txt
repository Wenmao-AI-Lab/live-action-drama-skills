# 阿拉丁·AI短剧封面海报工坊（aladin-drama-cover）

━━━━━━━━━━━━━━━━━━━━ 淘宝店AI灵匣 ━━━━━━━━━━━━━━━━━━━━

## 它解决什么痛点

| 痛点 | 后果 | 本技能给什么 |
|------|------|-------------|
| 封面随手截一帧 | 0.5 秒被划走 | 六式构图模板按峰值情绪确定性匹配 |
| 标题拍脑袋 | 点击率全靠运气 | 标题候选按点击信号打分优选（先截断再打分） |
| 只做一版没得测 | 不知道哪版能跑 | 每张封面 A/B 双版（人物向/文字海报向） |
| 封面脸≠正片脸 | 观众点进来出戏 | 可注入角色一致性锚 + 角色专属 seed |
| 每个平台规格不同 | 反复重做 | 六平台规格字典一键切换（限长/比例/角标） |

**本技能 = 短剧封面海报素材设计（上架素材层）**，脚本零依赖（仅 Python 标准库）、纯本地、离线可用，产出 **构图方案 + 打分标题 + A/B 双版 + 生图提示词/seed + HTML 看板 + 批量生图清单**。

## 与自家 aladin-drama 系列的闭环衔接

```
drama-script(_script.json) ──→ 本工坊 cover_ingest（素材归一）
drama-cast(cast_cards.json) ──→ 本工坊（角色外貌锚注入，封面脸=正片脸）
本工坊 _cover.json.feedback ──→ drama-publish（上架排期引用封面 id）
封面投后点击数据 ──→ drama-insight（验证 A/B 哪版胜出，迭代标题词表）
```

- 与 `aladin-drama-publish`（上架计划/元数据）分工：publish 管「发哪、何时发、写什么简介」，本款管「封面长什么样」（素材），封面 id 供 publish 排期引用。
- 与 `aladin-drama-clip`（切片素材）分工：clip 管动态视频素材，本款管静态封面海报素材。

## 能力边界

**能做**：剧本素材归一（双契约）；六式构图模板确定性匹配；标题点击信号打分（身份词/反转词/冲突词/悬念问句/限长惩罚，先截断再打分）；系列+分集 A/B 双版矩阵；中英双语生图提示词装配（可注入角色锚）；md5 派生确定性 seed；六平台规格切换；弱封面集检出与回灌建议；HTML 看板 + MD 方案书 + CSV 生图清单。

**不能做**：不真实生成图片（产出提示词与 seed，生图交给你选择的文生图工具）；不保证点击率（CTR 信号是结构信号非预测承诺）；不重写标题文案（弱封面标题润色交给 Hy3）；不联网抓平台实时规则；不处理成片视频帧截取。

## 重要约束

1. **不联网、零付费**：三个脚本仅 Python 标准库，剧本全程不出本机（短剧内容是核心商业资产，泄露=被抢拍/搬运）。
2. **可复算**：构图匹配/标题打分/seed 派生均为确定性规则，同输入必同输出，可进 CI。
3. **不臆造**：标题只从钩子/转折/台词中优选截取，不虚构剧情；CTR 信号分是排序信号，非点击率承诺。
4. **人机分工**：脚本管「构图选哪式、标题谁得分高、seed 是多少」（结构与规则），Hy3 管「弱封面标题怎么改爆、副标题润色」（语义与文采）。
5. **生图解耦**：提示词与 seed 通用于即梦/可灵/海外文生图模型，换模型不换工序。
