━━━━━━━━━━━━━━━━━━━━ 淘宝店AI灵匣 ━━━━━━━━━━━━━━━━━━━━

## 它解决什么痛点

| 痛点 | 后果 | 本技能给什么 |
|------|------|-------------|
| 项目做到哪了说不清 | 交接/汇报靠翻文件夹 | 15 环节完成度盘点+驾驶舱看板 |
| 剧本改了下游没重跑 | 字幕/配音/切片全是旧的 | 时序体检自动揪出过期产物 |
| 新旧契约不兼容直接 crash | 剧本喂视频生成环节报错 | 契约识别 + --fix 一键适配修复 |
| 集数/付费墙对不上 | 上架配置失败、返工 | 跨产物一致性核对 |
| 合规没过就排上架 | 下架/限流风险 | 门禁联动 P0 阻断提醒 |
| 不知道下一步干什么 | 团队空转 | 按闭环拓扑排出可执行行动清单 |

**本技能 = AI 短剧流水线总控层**，脚本零依赖（仅 Python 标准库）、纯本地、离线可用、只读扫描不改动项目文件（--fix 仅新增适配文件），产出 **环节盘点 + 健康体检 + 契约修复 + HTML 驾驶舱 + 行动清单**。

## 与阿拉丁 AI 短剧创作闭环的衔接

本技能是 aladin-drama 系列的**总控环**：topic(选题)→script(剧本)→gen(视频生成)/cast(角色)→dub(配音)/bgm(配乐)/subtitle(字幕)→edit(剪辑)→money(变现)/comply(合规)/clip(切片)→publish(上架)→traffic(引流)/i18n(出海)→insight(复盘)。上述任一环节的产物落进项目目录，本技能即可识别盘点；`_hub_health.json` 内含 `feedback` 契约（完成度/阻断环节/下一环节），可供后续环节联动。**不依赖任何环节技能也能独立使用**——只要项目目录按同名契约文件组织即可。

- 要**创作**具体环节内容（写剧本/切片/配乐等）——用对应的 aladin-drama 环节技能，本技能只管盘点与体检

## 能力边界

**能做：**
- 扫描项目目录，识别 15 环节契约产物，判定 done/partial/todo 与完成度
- 五类确定性体检：JSON 损坏、新旧契约识别（可 --fix 自动适配）、断链、时序过期、跨产物一致性
- 100 分制健康分（P0 扣 25 / P1 扣 10 / P2 扣 3）+ A-D 级 + READY/REVIEW/BLOCK 门禁
- 按闭环拓扑生成下一步行动清单（含各环节推荐命令）
- 产出自包含 HTML 驾驶舱（流水线地图 SVG）+ Markdown 行动清单 + feedback 回灌契约

**不能做：**
- 不生成/修改任何创作内容（剧本、提示词、切片方案等）——只做盘点体检
- 不执行下游环节脚本——只给导航建议，跑不跑由用户决定
- 不联网、不上传项目数据、不调用任何云端 API
- 不校验视频/音频成片本身的质量——只体检契约产物文件
- --fix 之外不改动用户任何文件（且 --fix 只新增 _script_genready.json，不覆盖原件）

```bash
python scripts/hub_scan.py <项目目录> --out _hub_ir.json
```

只读扫描项目目录（含 build/out/dist 子目录），输出 15 环节的状态、产物、mtime、JSON 可解析性。

### Step 2：健康体检（可选 --fix）

```bash
python scripts/hub_check.py _hub_ir.json --fix --out _hub_health.json
```

跑 K1-K5 五类体检，输出健康分/门禁/问题清单/下一步行动。`--fix` 会对旧契约剧本自动生成 `_script_genready.json`（原文件不动）。


产出自包含 HTML 驾驶舱与 Markdown 行动清单，可直接发给团队。

## 重要约束

- **不联网**：全部计算在本地完成，项目数据不出本机——短剧剧本与经营数据是核心商业资产（→ Trust）
- **可复算**：五类体检全部为确定性规则，同一输入必得同一结果，问题清单可追溯到具体文件（→ Reliability）
- **不臆造**：体检只报告文件层面可验证的事实，不推测创作质量；一致性核对仅在字段可读时进行（→ Trust）
- **只读优先**：扫描与体检不修改任何项目文件；唯一写动作 --fix 也只新增文件不覆盖（→ Reliability）
- **契约中立**：不依赖特定环节技能实现，任何按同名契约文件组织的项目均可盘点（→ Adaptability）
- **人机分工**：体检结论供人决策，上架/整改等外部动作由用户确认执行（→ Empowerment）
