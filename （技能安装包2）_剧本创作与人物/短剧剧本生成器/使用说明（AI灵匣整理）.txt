# AI短剧剧本创作

多模型协作的AI短剧/视频剧本全流程创作工具。大纲→Kimi，正文→文心一言，分镜→DeepSeek产出含AI提示词的Markdown分镜脚本（提示词可供后续文生图模型使用）。

## 快速开始

用户触发本Skill后，**首先执行需求确认**，收集作品参数后，再按三阶段推进创作。

### 第0步：需求确认（必做）

向用户询问以下参数，全部确认后才开始创作：

| 参数 | 说明 | 示例 |
|---|---|---|
| 作品类型 | 情感/悬疑/爽剧/古风/都市/玄幻/甜宠/年代等 | 都市逆袭爽剧 |
| 画面比例 | 竖屏9:16 或 横屏16:9 | 竖屏9:16 |
| 视频总时长 | 30秒~60分钟 | 3分钟 |
| 集数 | 单集或多集（可选） | 单集 |
| 风格基调 | 写实/动漫/水墨/赛博朋克等 | 写实电影感 |
| 目标平台 | 抖音/B站/YouTube等（可选） | 抖音 |

确认后生成《创作需求卡》保存到工作目录，后续每步都引用此卡。模板见 [TEMPLATES.md](TEMPLATES.md)。

━━━━━━━━━━━━━━━━━━━━ 淘宝店AI灵匣 ━━━━━━━━━━━━━━━━━━━━

### 第1步：大纲写作（模型：Kimi）

将需求卡 + 大纲模板投喂给 **Kimi**，生成结构化大纲：

- 一句话概念（Logline）
- 三幕式骨架（悬念钩子 → 主体推进 → 终局收束）
- 人物关系图谱（主角 + 4个关键角色）
- 每幕情绪节奏与钩子设计
- 镜像反转设计（适用于30分钟+）

大纲模板见 [TEMPLATES.md](TEMPLATES.md)，方法论见 [REFERENCE.md](REFERENCE.md)。

━━━━━━━━━━━━━━━━━━━━ 淘宝店AI灵匣 ━━━━━━━━━━━━━━━━━━━━

### 第2步：正文细化（模型：文心一言）

将大纲 + 剧本格式规范投喂给 **文心一言**，逐场景细化正文：

- 场景标题：`[序号] [地点] [时间] [内外景]`
- 动作描写：1句话，只写观众能看到的内容
- 对白格式：`角色名：（动作/情绪）台词内容`
- **三不写**：不写长句、不写客套话、不写无情绪台词
- **三要写**：写扎心话、写打脸话、写留钩子话

格式规范详见 [REFERENCE.md](REFERENCE.md)。

━━━━━━━━━━━━━━━━━━━━ 淘宝店AI灵匣 ━━━━━━━━━━━━━━━━━━━━

### 第3步：分镜头编排（模型：DeepSeek）

将正文 + 分镜术语规范投喂给 **DeepSeek**，产出 **Markdown格式的分镜头脚本文档**。文档中的"AI提示词"列内容可供后续文生图模型使用来生成画面。DeepSeek的逻辑推理能力适合分镜节奏规划、景别选择和提示词结构化生成。

**分镜头脚本**含：镜号/时长/景别/运镜/机位/画面内容/台词/音效/字幕/转场/AI提示词/备注。

**AI提示词列**：为每个镜头生成对应的文生图提示词，遵循公式 `主体 + 场景 + 动作 + 表情 + 光影 + 风格 + 构图 + 画质`，后续可直接投喂文生图模型。

**后续画面生成 - 文生图模型选择参考**（用户按需选用，将分镜脚本中的AI提示词投喂给以下模型）：

| 场景 | 推荐模型 | 核心理由 |
|---|---|---|
| 日常创作/中文用户 | 即梦AI | 中文友好、免费额度、竖屏优化、抖音生态契合 |
| 追求画质+一致性 | Flux Pro | 角色一致性94.7%、照片级写实、API批量调用 |
| 极致视觉质感 | Midjourney v7/v8 | 电影级光影、`--cref`角色锁定、风格覆盖最广 |
| 本地自主可控 | SD+ComfyUI | LoRA+ControlNet、完全免费、批量自动化 |

术语规范和提示词指南详见 [REFERENCE.md](REFERENCE.md)，分镜表模板见 [TEMPLATES.md](TEMPLATES.md)。

## 输出规范

- 全部输出为 Markdown 格式
- 大纲、正文、分镜分别保存为独立 `.md` 文件
- 分镜表使用标准 Markdown 表格
- 竖屏/横屏的景别和构图差异严格遵守 [REFERENCE.md](REFERENCE.md) 规范
- 每步完成后向用户展示结果，确认后再进入下一步
