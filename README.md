# 真人短剧 Agent 技能包

整理真人短剧相关的 Agent 技能文件与工作流，方便团队下载、学习和使用。

## 下载与安装

1. 在仓库文件列表中找到技能包。
2. 点击文件，选择下载。
3. 解压后，先阅读包内说明。
4. 根据对应 AI 工具的要求安装和配置。

## 使用说明

- 具体功能、输入材料与操作步骤以各技能说明为准。
- 部分功能可能需要额外软件、模型服务或 API 配置。
- 生成结果需要人工检查，尤其是剧情连贯性、人物一致性与音画效果。

## 问题反馈

反馈问题时，请提供：
- 技能名称及使用的 AI 工具
- 电脑系统
- 操作步骤
- 报错信息或截图

请勿提交密码、API 密钥或未获授权公开的素材。
